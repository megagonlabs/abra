# Display-view sample media

- `image_1.webp` … `image_10.webp`: procedural landscape scenes generated by
  [`gen-display-assets.mjs`](../../gen-display-assets.mjs). Regenerate with
  `node apps/playground/gen-display-assets.mjs` (renders with the workspace's Playwright
  Chromium: `pnpm exec playwright install chromium` once).
- `abra-emnlp2026-demo-p1.pdf`: the first page (title, Figure 1, abstract) of the ABRA system-demo
  paper (EMNLP 2026), used by the Document scenario.

Nothing here is third-party media. The playground scenarios reference these filenames; overwrite
any of them with your own images or PDF to try real media, and nothing else needs to change.

In the hub-driven demo (not the playground), media comes from whatever URL an agent puts in a
gallery item's `src`, for example a result of the `image_search` tool. This folder is not involved.
